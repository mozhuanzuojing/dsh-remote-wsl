## 契约变更（给下游/文档读者的差异）

1. **client chunk 多一个**：`client/client.panel.a11y.js`（面板 chunk 现 8 个，总数 13）。按规则入口
   `client/index.js` 已同步 bump `rev`；`check-client-rev` 通过。
2. **面板 host 错误体**统一为 `{ ok:false, error, code, detail?, reason? }`；新增
   `E_ORIGIN` / `E_METHOD` / `E_CONTENT_TYPE` / `E_BODY` / `E_UNKNOWN_METHOD`，
   `reason` 取值 `cross-origin` / `bad-verb` / `not-json` / `bad-json` / `unknown-method` / `unknown-distro`。
3. **`snapshot.webHosts[].url` 已脱敏**（`token=***`，保留 host:port）：诊断区与「复制诊断」都不再出现
   明文 token；`:pre` 仍渲染整份 snapshot，只是 token 被打码。
4. **视觉 token**：`.dsh-rw-sessionmeta` 从 `label-tertiary`（3.71:1，不符 4.5:1，且不在 17 token 闭集）
   改为 `label-secondary`；新增 `.dsh-rw-targetmain`（发行版行的原生按钮主操作）。
5. **fs provider**：`streamText` 返回真 `AsyncIterable<string>`（1MiB 分块）；`readText` 上限可配
   （默认 16MiB）；版本令牌 = `dev:ino:size:mtimeNs:ctimeNs`；`createIfAbsent` 改 `link(2)` 独占发布；
   `resolve()` 走 realpath；`processPath` 拒绝文件名内的 `\`。
6. **搜索**：rg/fd 加 `--no-ignore`（结果集与 GNU grep 对齐）；grep 归一 `\d`/`(?i)` 等并在 warnings
   里回报；glob 支持真字符类与 `**/`；后端统一 `--null` 解析；工具安装改为**后台**进行（搜索不再被
   安装阻塞），失败可见。
7. **守护**：协议三道上限（单帧/连接数/连接空闲）；启动锁（状态目录 `ensure.<slot>.lock`）；
   二次 SIGTERM 不再跳过清理；busy（端口可连但不应答）不再被算作孤儿。
8. **状态自报**：`wsl_status` 打印 `plugin: dsh-remote-wsl@<version>`；配置的发行版不在列表里会告警。
