== RAW: directoryFlow 槽 —— spec / occupants / 优先级（实测，两次运行 + 一次对照）

运行环境：`dsh --profile t11 --port 8911 --no-open`，DSH_HOME 隔离（见 raw-08）。
两份原始数据取自被测实例页面本身：`ctx.slots.spec(key)` / `ctx.slots.entries(key)`。

--- RUN 1：T11_PRIORITY=10（探针 occupant 在 +10）---
sidebar.workspaces.directoryFlow  spec = {"kind":"single","scope":"root"}
  occupants = [
    {"registrant":"mf","priority":0,"componentName":"NativeDirectoryFlow"},
    {"registrant":"mf","priority":10,"componentName":"ProbeFlow"}
  ]
conversation.hero.workspace.directoryFlow  spec = {"kind":"single","scope":"root"}
  occupants = [ {"registrant":"mf","priority":0,"componentName":"NativeDirectoryFlow"} ]

页面 DOM（普通加载，未打开任何菜单）:
  document.querySelectorAll('[data-t11-flow]').length === 0        <-- 我们的 +10 没渲染

--- RUN 2：T11_PRIORITY=-10（同一份 bundle，只改 priority）---
sidebar.workspaces.directoryFlow  occupants = [
    {"registrant":"mf","priority":-10,"componentName":"ProbeFlow"},
    {"registrant":"mf","priority":0,  "componentName":"NativeDirectoryFlow"}
]
页面 DOM（普通加载，未打开任何菜单）:
  document.querySelectorAll('[data-t11-flow]').length === 1
  -> <div data-t11-flow="im">T11-FLOW-WINNER role=im open=false busy=false</div>
     （内文 "T11-FLOW-WINNER role=im open=false busy=falsepick"；owner props {open,busy} 已被传入）

--- RUN 3：对照（把唯一的 immediately 包从 bundles 移除，且没有任何包注册该槽）---
  document.querySelectorAll('[data-t11-flow]').length === 0
  -> 证明 RUN 2 里该元素出现确实来自我们的注册，不是别的东西。

== 结论（实测）==
1. 两个槽都是 `single` kind、scope `root`。
2. `single` 槽是"每 cell 一个 winner"，胜者 = **priority 最小者**：
   - priority 0（官方） vs priority +10（我们） -> 官方赢，我们不渲染（RUN 1）
   - priority 0（官方） vs priority -10（我们） -> 我们赢（RUN 2）
   - 两次唯一的变量就是 priority，且 RUN 3 排除了"元素来自别处"的解释。
3. 官方 occupant = `NativeDirectoryFlow`，来自包 `@deepseek-ai/dsh-client-ui-directory-picker-native`
   （注册点：`.../dsh-client-ui-directory-picker-native/lib/client.js:66-75`，注册时**不写 priority** ⇒ 默认 0）。
   另一个官方实现 `.../dsh-client-ui-directory-picker-browse` 同形（`lib/client.js:1027-1035`），
   但**本机 web 组合里没有加载它**（boot graph 的 picker 条目只有 -native，见 raw-06）。
4. 槽由 `@deepseek-ai/dsh-client-ui-workspace` 声明为子槽：
   - `sidebar.workspaces.directoryFlow` <- 挂在 `sidebar.workspaces` entry 的 children（client.js:4299-4305）
   - `conversation.hero.workspace.directoryFlow` <- 挂在 `conversation.hero.workspace` entry 的 children（client.js:4398-4406）
